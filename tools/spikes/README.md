# Reverse Engineering Spikes & Probes

This directory contains standalone exploratory scripts and CDP injection probes from early reverse engineering of the PTIT / ED22 courseware:
- `api_spike.py`: direct HTTP session probe.
- `probe_*.js`: Angular component, scope, and service inspector snippets.
- `hook_net.js`: early network hook prototype.
- `l1test.py`, `goto_l4.py`, `open_l4.py`, `start_l4.py`, `fix_cloze.py`: one-off lesson debugging scripts.
- `killchrome.py`, `killpy.py`: emergency process termination one-liners.
- `tr.py`: transcription testing snippet.
